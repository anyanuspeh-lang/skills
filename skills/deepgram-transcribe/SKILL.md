# Deepgram Transcribe Skill 🎙️

Навык для мгновенного перевода речи в текст из любых локальных аудио/видео файлов или онлайн-ссылок с использованием моделей Deepgram (Nova-3).

## Возможности
* Поддержка любых ссылок (YouTube, Rutube, VK Видео, Telegram, Vimeo, прямые mp3/mp4 ссылки) через связку с `yt-dlp`.
* Поддержка всех форматов локальных медиафайлов (mp3, wav, m4a, ogg, mp4, mov, mkv) с автоматической конвертацией через `ffmpeg`.
* Автоматическая разбивка по спикерам (Спикер 0, Спикер 1) и таймкодам `[MM:SS]`.
* Поддержка русского, английского и автоопределения языка.

## Использование
Скрипт транскрибации находится в директории `scripts/transcribe.py`:

```bash
# Транскрибация локального файла:
python3 <path/to/skill>/scripts/transcribe.py "/path/to/audio_or_video.mp3" -o transcript.md

# Транскрибация по онлайн-ссылке (YouTube и др.):
python3 <path/to/skill>/scripts/transcribe.py "https://www.youtube.com/watch?v=..." -o transcript.md

# С автоопределением языка:
python3 <path/to/skill>/scripts/transcribe.py "https://..." -l auto -o transcript.md
```

## Алгоритм работы для ассистента:
1. Когда пользователь просит расшифровать аудио, видео или ссылку, вызовите скрипт транскрибации.
2. Прочитайте полученный файл транскрипции `transcript.md`.
3. Предоставьте пользователю:
   - Краткое резюме (Executive Summary) встречи/записи.
   - Список договоренностей, задач (Action Items) и ключевых мыслей.
   - Полную или структурированную расшифровку с таймкодами.
