# Пример пользовательского скилла

Этот скилл служит шаблоном для добавления новых навыков в Antigravity.

## Когда использовать
Используйте этот навык как образец при создании новых автоматизаций.

## Инструкции
1. Определите триггеры вызова скилла в поле `description` выше.
2. Опишите пошаговый алгоритм действий для ассистента.
3. При необходимости добавьте вспомогательные скрипты или справочные материалы.
