# My Antigravity Skills 🚀

Репозиторий для хранения, синхронизации и версионирования персональных навыков (Skills), промптов и автоматизаций для Google Antigravity.

## 📁 Структура репозитория

```text
skills/
├── README.md
├── .gitignore
└── skills/
    └── example-workflow/
        └── SKILL.md
```

## 🛠 Как устроен каждый скилл

Каждый скилл представляет собой изолированную папку в директории `skills/` и содержит файл `SKILL.md`:
* **Frontmatter** (`name`, `description`): метаданные, по которым ИИ-ассистент понимает назначение скилла и условия его вызова.
* **Инструкции**: пошаговое руководство, шаблоны и правила выполнения задачи.
* **Скрипты** (опционально): вспомогательные исполняемые файлы (`scripts/`).

## 🔄 Синхронизация

Все скиллы из этого репозитория могут быть синхронизированы в локальную среду Antigravity:
`~/.gemini/antigravity/skills/`
